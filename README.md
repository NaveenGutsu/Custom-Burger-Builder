# Build-A-Burger CLI

A lightweight Python project demonstrating the power and flexibility of **default arguments** and keyword parameters in Python functions.

---

# About The Project

Just like ordering at a burger joint where you get a classic burger unless you ask for special ingredients, Python functions can have default values ready to go! 

This CLI program lets users order burgers by either sticking with standard recipes or customizing buns, patties, sauces, and toppings using named arguments.

---

# Key Features

- **Default Parameters:** Standard ingredients are automatically applied when no arguments are passed.
- **Named Overrides:** Swap individual ingredients (e.g., just the sauce) without altering the rest of the defaults.
- **Full Customization:** Freedom to override every parameter for completely custom orders.
